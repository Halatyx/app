## ✨ 软件特色

* **即点即播，告别卡顿**  
  针对高码率与高分辨率视频做了底层渲染优化。拖拽进度条不卡顿，全屏与窗口切换顺畅，播放不掉帧。

* **双端支持，体验统一**  
  Windows 电脑和 Android 手机一套界面逻辑，操作习惯无缝过渡，不需要重新学习。

* **轻巧纯粹，无杂质**  
  软件体积轻便，没有多余的捆绑内容和弹窗推广，专注做好视频播放本身。

### 1. Windows 用户
* 在 Releases 页面下载 `Halatyx_Windows_x64.zip`。
* 右键解压该压缩包到你常用的软件文件夹。
* 双击运行文件夹内的 `Halatyx.exe` 即可启动（可在桌面上创建快捷方式方便下次使用）。

### 2. Android 用户
* 在手机浏览器中打开 Releases 页面，下载 `Halatyx_Android.apk`。
* 下载完成后点击安装。如系统提示“允许安装来自未知来源的应用”，点击允许后即可顺利完成安装。
