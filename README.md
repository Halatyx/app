## ✨ 软件特色

* **即点即播，丝滑流畅**

## 📥 获取与安装

可在当前仓库的 Releases 发布页面获取对应平台的预编译安装包：

### 1. Windows 用户
* 获取压缩包 `Halatyx_Windows_x64.zip`。
* 解压至常用目录，双击运行主程序 `Halatyx.exe` 即可启动（可右键创建桌面快捷方式）。

### 2. Android 用户
* 获取安装包 `Halatyx_Android.apk`。
* 点击下载文件并安装；如系统提示“允许安装未知来源应用”，授权后即可正常完成安装。

## ❓ 常见问题解答

**Q：软件是否完全免费？**  
A：Halatyx 目前完全免费提供使用，核心功能无任何隐藏门槛。

**Q：后续版本如何更新？**  
A：客户端内置版本检查机制。检测到新版本时会自动发出更新提醒，也可随时前往 Releases 发布页面下载最新版本覆盖安装。

**Q：特定格式视频播放异常或黑屏？**  
A：请优先更新至当前最新版本，并确保系统显卡驱动已更新至稳定版本。
